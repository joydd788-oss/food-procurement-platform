# 食材集中采购与监管平台 · 用户操作手册

本手册面向平台的日常使用者：监管员/管理员、采购员、供应商。覆盖登录、界面、各模块操作、采购闭环流程与常见问题。

## 1. 快速开始

### 1.1 访问与登录

1. 在浏览器打开系统地址（本机部署为 `http://localhost:8080`，服务器部署为 `http://<服务器IP>:8080`）。
2. 输入用户名与密码，点击「登录」。
3. 用户名和密码由管理员在部署时配置（见 `.env` 中的 `ADMIN_USERNAME/ADMIN_PASSWORD`、`BUYER_*`、`SUPPLIER_*`）。

### 1.2 退出登录

点击右上角的「退出」即可。

### 1.3 三种角色

| 角色 | 用户名（默认） | 能做什么 |
|---|---|---|
| 监管员/管理员 | `admin` | 查看监管驾驶舱 + 管理全部业务模块 |
| 采购员 | `buyer` | 管理除驾驶舱外的全部业务模块 |
| 供应商 | `supplier` | 仅查看询价列表、提交/查看自己的报价 |

## 2. 界面总览

登录后左侧是功能菜单，顶部显示当前用户名与角色，右侧是内容区。

- 监管员/管理员：菜单包含「监管驾驶舱」和全部业务模块。
- 采购员：菜单为除「监管驾驶舱」外的全部业务模块。
- 供应商：菜单只有「询价/竞价」。

## 3. 通用操作

每个业务模块都是「列表 + 搜索 + 新增」的形式。

### 3.1 查看与搜索

- 列表默认分页显示，每页可选 10 / 20 / 50 / 100 条。
- 顶部搜索框输入关键字后回车或点「搜索」，按各模块的主字段模糊匹配。
- 点「刷新」重新加载当前列表。

### 3.2 新增记录

1. 点右上角「新增」。
2. 在弹窗中填写表单，带红色星号的为必填项。
3. 点「保存」，成功后列表自动刷新。

### 3.3 表单字段类型

- 文本：直接输入。
- 数字：金额、评分、数量、温度等，可点击上下箭头微调。
- 日期 / 日期时间：点击选择日期或时间。
- 下拉选择：状态、验收结果、资质状态等，从预设选项中选择。
- 关联下拉：供应商、采购计划、订单等，从已存在的数据中搜索选择。
- 开关：启用/停用。

## 4. 分角色操作流程

### 4.1 采购员 / 监管员（建设基础数据）

1. 在「食材标准库」维护食材标准（编码、名称、品类、规格、安全要求）。
2. 在「供应商」维护供应商档案。
3. 在「采购计划」建立采购计划。

> 重要：供应商档案中的「登录账户名」字段必须与该供应商的登录用户名一致，供应商登录后才有资格报价。例如供应商账号为 `supplier`，则其档案的「登录账户名」填写 `supplier`。

### 4.2 采购员 / 监管员（发起询价并下单）

1. 在「询价/竞价」新增询价，状态选择 `OPEN`，可关联采购计划、设置截止时间。
2. 供应商报价后，在询价列表点击「报价/查看」查看各家报价。
3. 选定供应商后，在「采购订单」新建订单。
4. 依次在「配送」新建配送单、在「智能验收」录入验收结果、在「库存批次」录入入库批次、在「结算」创建结算单。

### 4.3 供应商（查看询价并报价）

1. 登录后进入「询价/竞价」，查看询价列表。
2. 对状态为 `OPEN` 的询价，点「报价/查看」。
3. 填写报价金额（元）与备注，点「提交报价」。
4. 同一询价可重复报价，系统以最新一次报价为准。
5. 只能看到自己的报价；管理员/采购员可看到所有供应商的报价。

### 4.4 监管员（监管驾驶舱）

登录后首页即「监管驾驶舱」，展示：食材标准数、供应商数、采购计划数、进行中询价、订单数、库存批次、待结算账款等统计。

## 5. 模块字段说明

### 5.1 食材标准库

字段：编码、名称、品类、规格、安全要求、启用。

### 5.2 供应商

字段：供应商名称、统一社会信用代码、登录账户名、联系人、联系电话、资质状态（待审核/已认证/已过期/被吊销）、评分（0–9.99）、启用。

### 5.3 采购计划

字段：计划编号、标题、采购机构、预算、状态（草稿/审批中/已批准/执行中/已完成/已取消）、需求日期。

### 5.4 询价/竞价

字段：询价编号、标题、关联采购计划、截止时间、状态（OPEN/CLOSED）。

### 5.5 采购订单

字段：订单编号、供应商、关联计划、总金额、状态（待确认/已确认/配送中/已完成/已取消）、期望配送日期。

### 5.6 配送

字段：配送单号、关联订单、车牌号、状态（待配送/在途/已送达/异常）、送达时间。

### 5.7 智能验收

字段：关联配送单、验收员、验收结果（合格/不合格）、温度、备注。

### 5.8 库存批次

字段：批次号、食材标准、供应商、数量、单位、入库日期、到期日期、状态（在库/已出库/临期/过期）。

### 5.9 结算

字段：结算单号、关联订单、金额、状态（待结算/已开票/PAID）、到期日。

## 6. 完整业务流程示例

以一次食堂采购大米为例：

1. 采购员在「食材标准库」新增「大米」标准。
2. 在「供应商」新增供应商档案，并填写其「登录账户名」。
3. 在「采购计划」新增「2026 年秋季大米采购计划」，设置预算。
4. 在「询价/竞价」新增询价，关联该计划，状态 `OPEN`，设置截止时间。
5. 供应商登录后对该询价提交报价。
6. 采购员在「报价/查看」中比较报价，选定供应商。
7. 在「采购订单」新建订单，填写供应商、总金额。
8. 在「配送」新建配送单，关联订单。
9. 在「智能验收」录入验收员、验收结果、温度。
10. 在「库存批次」录入批次号、数量、入库日期、到期日期。
11. 在「结算」新建结算单，关联订单并填写金额。
12. 监管员在「监管驾驶舱」查看全局统计。

## 7. 常见提示与处理

| 提示 / 现象 | 含义与处理 |
|---|---|
| 用户名或密码错误 | 登录凭据不正确，核对用户名与 `.env` 中的密码 |
| 无法连接服务 | 后端未启动或未就绪，联系管理员检查 `docker compose ps` |
| 保存失败：xxx 不能为空 | 有必填字段未填写，补全后重试 |
| 数据违反唯一性或完整性约束 | 编号/代码等唯一字段重复，或引用了不存在的数据 |
| 询价已关闭，无法报价 | 该询价状态不是 `OPEN`，或已过截止时间 |
| 报价已截止 | 已超过询价设置的截止时间 |
| 供应商无法报价 | 确认询价状态为 `OPEN`，且供应商档案的「登录账户名」与该供应商登录名一致 |
